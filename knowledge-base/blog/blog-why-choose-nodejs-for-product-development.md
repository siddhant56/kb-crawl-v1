## A Quick Introduction to Node.js with Some Usage Statistics

NodeJS is an open-source and cross-platform JavaScript runtime that is used for server-side programming of real-time, push-based architectures. Created by Ryan Dahl in 2009, NodeJS is designed to handle high volumes of concurrent connections leveraging a single-threaded event-loop architecture, asynchronous call-back function, and non-blocking I/O model. It is a powerful tech stack that is apt to build fast and lightweight web applications with 60% reduced load time. Additionally, it brings 10x agility in your web apps to handle 6x traffic spikes without downtime, manage 10x loads of server-side client queries or requests, and scale at 5x speed.

To put it simply, Node JS has emerged as a universal tech stack created to meet specific demands of modern web-connected apps that perpetually gather data from different sources pushing it to numerous clients in real-time. Developers around the world use this JavaScript runtime environment (RTE) for server-side scripting and command-line utilities.

Node JS enables unify web application development around a single programming language with JavaScript being used both in frontend and backend. This implies that the entire web app runs across a ‘unified environment’ which in turn makes development and maintenance quick and easy.

The fact that NodeJS is open source comprising 1.3 million packages and modules available in the NPM’s main registry implies it is free to use. This broadens the scope for developers to get easy programming solutions for complex product feature needs.
