# Radix Releases MatchMe Memory Game for iPhone & Android

Feb 4, 2012

Radixweb, an India-based technology development and consulting company, has released MatchMe, a memory game, for iPhone & Android users. The gaming app is available on app store.

MatchMe is a gaming app that tests a user’s visual memory. It requires users to memorize the location of different visuals in the image boxes and match them by opening the relevant box. The game has two fundamental complexity levels – Easy with 4x4 matrix and Hard with 6x6 matrix. The game maintains a score based on the number of taps a user takes and the amount of time he spends on finishing a matrix. The game’s scoreboard shall display the top ten players with minimum number of taps and time taken as competition benchmark.

“The good thing about this game is that it randomly loads images in the matrix. This keeps the user thinking and makes it more challenging for him every single time to complete a matrix”, informs Pratik Mistry, Sr Business Head, Radixweb.

MatchMe is a gaming app that targets both iPhone and Android users. Revealing the strategic decision behind this, Dharmesh Acharya, COO, Radixweb comments, “Before developing the game, we conducted a market research that showed that memory games were extremely popular with both iPhone and Android. We didn’t want to limit ourselves to only one audience base. So we developed MatchMe in such a way that it is compatible with iPhone and Android platforms.”

MatchMe is another addition to the list of mobile apps developed by Radixweb. The other apps developed and released by Radix include Kites – Soaring High, PersonalSMS, & Online Print Store. “We have also developed a mobile compliance tool, MinusStamp, and iPhone GPS for our customers”, states Mr Acharya.
