## Frequently Asked Questions

### What is Tailwind CSS?

Tailwind CSS is a utility-first CSS framework for robustly building customized web apps. It’s a low-level CSS framework that allows you to develop designs avoiding opinionated component styles that you would anyway wish to override.

### What does Tailwind CSS do?

Tailwind CSS framework is used to build a beautiful user interface without putting in the coding efforts. It best renders our ability to style every component distinctively, exactly how you want your app to be designed.

### Is it worth using Tailwind CSS?

Tailwind automatically removes all unnecessary CSS when it's time to build for the web. It helps to make the CSS bundle (Tailwind webpack) as small as possible at the end. Tailwind also lets developers build responsive designs right in HTML, which significantly reduces costs.
