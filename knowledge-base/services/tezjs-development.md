### 98+ Core Web Vitals

TezJS uses Component-driven Architecture and ViewPort-based loading, which helps you optimize the website and achieve 98+ Google Core Web Vitals scores

### Search Engine Friendly

TezJS site first loads as static HTML before it hydrates into a fully Vue.js-enabled SPA. This allows search engines to crawl the page and shows a faster result

### Lightweight

TezJS is a small size to start with among web frameworks. It is a lightweight framework offering outstanding performance and quality at a faster speed

### Fast Speed

With pre-defined features like lazy loading, image optimization, prefetching resources, and many more, TezJS ensures to deliver faster web performance for search engines

### Robust Security

TezJS has no server and no database. Therefore, a website built with TezJS has no space for DDOS attacks, accidental exposure, or malicious requests

### Development Experience

TezJS enables more targeted deployment and debugging with loose coupling and separation of controls, leading to efficient website development
