## Why Choose SQLite

### Zero Configuration

SQLite does not require setup. Other databases require configuration settings for system installations. SQLite does not require a server process making it a zero configuration system.

### Serverless

Most SQL database engines create separate server processes. SQLite does not require any management or trouble shooting operations making it serverless and maintenance free.

###  Lightweight Single File

SQLite, true to its name, is a lightweight single ordinary disk file with a minimal size of 500KB which can be located anywhere in the directory structure to store required database contents.

### Manifest Typing

SQLite supports manifest typing different from the static typing mechanism of other databases. It enables storage of values of any datatype into any column regardless of declared types.

### Minimal Footprint

The default build of SQLite is less than one Mb of code and it requires only a few Mb of memory in runtime thus significantly reducing library size and memory use with minor adjustments.

###  Self-contained

The entire database system of SQLite is contained in a single library which integrates into a host application. Administration is not required as it resides in a cross-platform file.
