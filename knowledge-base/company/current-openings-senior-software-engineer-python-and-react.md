### How you should be?

A passionate full-stack developer with a strong foundation in Python (Flask/FastAPI) and React/Next.js, eager to build intelligent web applications that leverage AI and automation.

You have a curious mindset, a love for learning new tools like LangChain and n8n, and the ability to translate technical requirements into seamless, production-ready code.

### What you will do?

  * Develop and maintain backend services using Python (Flask/FastAPI) and modern frontend interfaces using React/Next.js.
  * Build, test, and integrate LLM-based features via LangChain, OpenAI, or Bedrock APIs.
  * Create n8n automation workflows for integrating APIs, databases, and microservices.
  * Design and optimize PostgreSQL schemas and queries for scalable data handling.
  * Collaborate with product, design, and AI teams to develop intuitive, intelligent features.
  * Implement unit testing, linting, and CI/CD pipelines to maintain code quality.
  * Ensure application performance, reliability, and maintainability across the stack.
  * Write clear documentation and contribute to knowledge-sharing within the team.

### What we are looking for?

  * 4–6 years of experience in Python + React/Next.js fullstack development.
  * Strong understanding of Flask/FastAPI frameworks and RESTful API design.
  * Familiarity with LangChain and LLM integration basics (RAG, prompt chains, embeddings).
  * Exposure to n8n automations or equivalent workflow tools (Zapier, Make).
  * Working knowledge of PostgreSQL and basic ORM concepts.
  * Familiarity with AWS services (S3, Lambda, API Gateway, EC2).
  * Experience with Docker, Git, and CI/CD pipelines.
  * Strong debugging, problem-solving, and collaborative communication skills.
  * Curious about AI, automation, and data-driven systems.

### Bonus Skills

  * Understanding of vector databases (Qdrant, Pinecone).
  * Knowledge of TypeScript and Next.js SSR principles.
  * Experience with AI API integrations or automation workflows in production.
  * AWS or equivalent cloud certification.
