# An Integrated Recruitment Software Solution

Developed a global portal for recruitment industry. Modernized feature-rich recruitment management system by using latest technologies to deliver an engaging experience and increased ROI.

  * Unique Feature for recruiters and job seekers to post and search jobs
  * Effective search algorithms powered by NLP to understand intent, improve keyword relevance, and surface the most suitable job matches, along with an internal chat feature
  * API Integration with Algolia Search for keyword-based search
  * Location based search and features to change database into private mode with Enterprise Subscription
  * Simplified workflow and intuitive user interface at reduced costs
