## Feature of Embedded System Development for Security System

  * DIGITAL KEYPAD or RF Remote Control
  * One master + 10 user code
  * Door + 3 independent security zones
  * Zones bypass facility
  * Auto dialer integration
  * Auto dialer trigger facility momentary + nc trigger
  * Auto latching mode with timer facility 1 sec to 99 sec, user programmable (anti tailgating)
  * 2 doors control output. Fail safe & fail secure locking mode
  * Users bypass facility
  * Led & buzzer indication on keypad
  * Temporary password option (suitable for hotel industry)
  * 3 wrong attempts jam the system for 30 sec and dials to a particular telephone number if dialer is installed
  * 9 wrong attempts will trigger the siren and dials all the numbers in dialer
  * Internal switch facility to lock or unlock the door
  * Door monitoring sensors
  * User friendly programming
  * Non volatile memory

E-locking-1 uses a very secure remote control that works at a very high frequency of 315 Mhz / 433.92 Mhz with billions and trillions of rolling code combinations which makes it secure.
