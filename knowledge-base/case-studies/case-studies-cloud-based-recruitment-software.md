# Cloud Based Recruitment Software Solution - Radixweb

> Leveraging modern cloud resources, Radixweb developed a cloud based recruiting software that offers improved recruiter experience and hiring efficiency.

**Source:** https://radixweb.com/case-studies/cloud-based-recruitment-software

---

## Project Brief

The task at hand was a strategic migration of a traditional platform to a cloud-based recruitment solution. It involved a complete rewriting of the legacy codebase, software refactoring, data migration, and integrating microservices.
