## Tech Stack Used

Considering the present and future goals of the tech startup, our team needed to make sure that we used the best technologies available for the HR and recruitment management software.

### Backend Development

For the backend, our tech stack featured Node.js for its scalability and event-driven architecture. Express.js for its RESTful APIs, and of course, MongoDB to accommodate the dynamic data structures in HR and talent management. The combination of these technologies formed a reliable and scalable foundation for the backend infrastructure.

### Frontend Development

We went for Vue.js development to create a responsive and dynamic user interface. Specifically, Vuex helped us with state management communication between different components. As part of the build process, we utilized Vite, a modern build tool, to speed up the development process and deliver optimized frontend assets.

### Database Management

For database management, we worked with PostgreSQL to create an efficient database management system for storing and retrieving HR data. This choice came from the need for a structured and foolproof database. Additionally, we utilized Redis as an in-memory data store to optimize the system performance.

### DevOps and Deployment

Azure DevOps provided the DevOps capabilities for our project. Using Azure Pipelines for CI/CD, we automated the build and deployment process with consistent and reliable releases. Azure Kubernetes Service (AKS) orchestrated container deployment and resource optimization within the Azure cloud environment.
